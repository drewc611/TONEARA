# Contributing

Toneara is currently proprietary and accepts contributions only with owner approval.

1. Open an issue describing the change and its user value.
2. Keep each pull request focused on one issue.
3. Run `npm run verify` before requesting review.
4. Include screenshots for visible changes and tests for behavior changes.
5. Do not add generation providers, telemetry, dependencies, or user-data collection without an approved architecture decision.

Commits should be concise and imperative. Pull requests require passing checks and owner review. AI-generated changes must be disclosed and reviewed like human-authored changes.
